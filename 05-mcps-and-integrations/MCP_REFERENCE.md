# MCP Server Reference

Quick reference for MCP servers covered in Module 05. See the [module README](README.md) for setup and key concepts.

Browse the full list of official and community servers at [modelcontextprotocol/servers](https://github.com/modelcontextprotocol/servers).

## General-Purpose

| MCP Server | Best For | Link |
|------------|----------|------|

## Project Management — Choose Based on Your Stack

| MCP Server | Best For | Link |
|------------|----------|------|
| GitHub | Issues, PRs, Actions | [github/github-mcp-server](https://github.com/github/github-mcp-server) |
| Azure DevOps | ADO work items, repos, pipelines | [microsoft/azure-devops-mcp](https://github.com/microsoft/azure-devops-mcp) |
| Atlassian | Jira + Confluence Cloud | [Atlassian Rovo MCP Server](https://www.atlassian.com/platform/rovo-mcp) |
| Linear | Issues, projects, milestones | [Linear MCP Server](https://linear.app/mcp) |
