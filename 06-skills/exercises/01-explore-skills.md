# Exercise 6.1: Explore Skills

## Objective
Discover what the skill ecosystem offers and understand how skills are structured.

## Background
A skill is a folder with a `SKILL.md` file whose frontmatter declares a `name` and `description`, optionally bundled with scripts, templates, and reference docs. Skills are loaded progressively: at first only the name and description reach the model, and the full body is pulled in when the skill is triggered. Before you install anything, it helps to see what already exists — the [skills.sh](https://skills.sh) catalog and the [awesome-copilot](https://github.com/github/awesome-copilot) repo collect community and official skills across many categories. This exercise is read-only: you browse and compare, so you have a mental model before Exercise 6.2 has you install your first skill.

## Steps
1. Browse [skills.sh](https://skills.sh) to explore the skill catalog.
2. Look across a few categories — note the variety: code review, documentation, testing, accessibility, etc.
3. Open two or three skill detail pages and read their descriptions.
4. Compare a skill that looks similar to something you could achieve with a plain prompt. What does the packaged skill add?
5. Make note of skills that could fit into your dev environment — either as-is or with minor tweaks.

## Expected Outcome
A clear mental model of what skills are, how they differ from plain prompting, and which categories exist — without needing to install anything yet.
